# Roadmap

## Milestone A — Local control plane
Phases 00–03. Fedora and Android communicate locally; browser dashboard displays health and can execute allowlisted actions.

## Milestone B — Native Android control
Phase 04. React Native client pairs, authenticates, reconnects and receives events.

## Milestone C — Device integrations
Phase 05. KDE Connect, scrcpy/ADB and Sunshine/Moonlight are coordinated through adapters.

## Milestone D — Codex cockpit
Phase 06. Remote view of Codex threads, tasks, diffs and approval requests without exposing unrestricted shell.

## Milestone E — Tool-native orchestration
Phase 07. DeviceBridge MCP exposes narrow, typed tools for Codex and automations.

## Milestone F — Anywhere access
Phase 08. Tailscale-only remote access, Wake-on-LAN relay design and opt-in secure unlock adapter.

## Milestone G — Hardened personal product
Phase 09. Packaging, audits, recovery, observability and release checklist.
