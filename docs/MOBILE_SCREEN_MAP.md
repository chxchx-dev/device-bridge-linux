# Mobile Screen Map

## Home
- Fedora online/offline.
- CPU/RAM/battery/temperature where available.
- Tailnet connectivity.
- Quick actions: Lock, Dev Mode, Game Mode.
- Remote wake button only if relay capability exists.

## System
- Service states.
- Suspend/shutdown actions with confirmation.
- Network path details.
- Audit history for recent actions.

## Codex
- Projects/workspaces.
- Active threads.
- Task progress.
- Changed-file summaries.
- Pending approvals.
- Approve/Deny with biometric step-up for sensitive requests.

## Gaming
- Sunshine status.
- Start Game Mode.
- Hand off to Moonlight.
- Network quality hints.

## Android/Fedora
- ADB connectivity state.
- scrcpy availability on Fedora.
- KDE Connect state.

## Files
Initial release should use safe, explicitly scoped roots. Do not build an unrestricted file browser over `/`.

## Security
- Paired device fingerprint.
- Revoke this device.
- Session/token rotation.
- Unlock feature state (disabled/experimental/enabled).
